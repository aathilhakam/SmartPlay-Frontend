# An AI-Driven Teacher-Assisted Learning System - Frontend

## 📌 Project Overview

This repository contains the frontend application for an AI-Driven Teacher-Assisted Learning System designed to support Grade 1 students through personalized and interactive learning experiences.

The system aims to enhance students' motor skills, creativity, critical thinking, and overall learning development through teacher-assisted and personalized activities.

The frontend provides dedicated interfaces for teachers, students, and parents.

---

## 🎯 Objectives

The frontend is designed to:

- Provide a user-friendly learning environment for Grade 1 students.
- Support teachers in monitoring and managing student learning activities.
- Provide personalized learning experiences based on individual student needs.
- Allow teachers to monitor student progress and performance.
- Support interactive educational activities.
- Provide parents with visibility into their child's learning progress.
- Present learning analytics and assessment results in an accessible format.

---

## 👥 User Roles

The system contains three main user interfaces:

### 👨‍🏫 Teacher Dashboard

Teachers can:

- View student information.
- Monitor student progress.
- Manage learning activities.
- View assessment results.
- Analyze student performance.
- Access personalized learning paths.

### 👧 Student Learning Interface

Students can:

- Access assigned learning activities.
- Participate in interactive activities.
- Follow personalized learning paths.
- Complete assessments.
- View their learning progress.

### 👨‍👩‍👧 Parent Portal

Parents can:

- View student progress.
- Monitor learning activities.
- View assessment results.
- Track overall learning development.

---

## 🧠 Personalized Learning

The frontend supports the personalized learning functionality of the system.

Student information, activity performance, assessment results, and learning progress can be presented to teachers to help them understand individual learning requirements.

The system is designed to support personalized learning paths based on student performance and learning needs.
